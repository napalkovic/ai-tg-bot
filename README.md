# ИИ-бот для Telegram

Личный бот-ассистент: пишешь сообщение — получаешь ответ. Сколько угодно чатов,
у каждого своя история и память. Основной источник — **бесплатный DeepSeek через
веб-чат** (по токену твоего аккаунта), резервный — любая бесплатная модель
(OpenRouter / Groq) на случай, если DeepSeek недоступен.

Бот приватный: отвечает только тем, кто указан в `OWNER_IDS`.

---

## Быстрый старт

```bash
./scripts/install.sh          # venv + зависимости + .env
```

Дальше:

1. Открой `.env` и впиши:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
   - `OWNER_IDS` — свой Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)).
2. Войди в DeepSeek (один раз, откроется окно браузера):
   ```bash
   ./scripts/ds_login.sh
   ```
   Войди в аккаунт chat.deepseek.com и пройди проверку «не робот». После входа
   окно закроется само, сессия сохранится в `session/`.
3. Запусти:
   ```bash
   ./scripts/start.sh
   ```

Всё. Пиши боту в Telegram.

## Запуск на сервере (бот работает без твоего Mac)

Бот использует long polling, поэтому ему **не нужен** ни домен, ни публичный IP —
достаточно любой машины, включённой круглосуточно. Ноутбук для этого плохо
подходит: при закрытии крышки бот замолкает.

### Куда поставить

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Render + Neon** (см. `deploy/RENDER.md`) | **бесплатно и без банковской карты**, деплой из публичного git-репозитория | засыпает без «пингера», история — только во внешней базе |
| **Oracle Cloud Always Free** (ARM Ampere, 4 CPU / 24 ГБ) | реально бесплатно и навсегда, мощно | регистрация с картой, иногда долго выдают инстанс |
| Google Cloud free `e2-micro` | бесплатно | 1 ГБ RAM, нужно следить за лимитами |
| Koyeb / Fly.io / Render (free) | деплой в пару кликов, Docker | засыпают или мало памяти |
| Любой VPS (Hetzner, Timeweb, Aeza) | 200–500 ₽/мес, стабильно | платно |
| Raspberry Pi / старый ноут дома | бесплатно, полный контроль | нужен свет и интернет 24/7 |

### Бесплатно и без карты: Render

Полная пошаговая инструкция — [`deploy/RENDER.md`](deploy/RENDER.md).
Коротко:

1. На Mac заполнить `.env` (`BOT_TOKEN`, `OWNER_IDS`), войти в DeepSeek
   (`./scripts/ds_login.sh`) и получить бесплатный ключ OpenRouter.
2. Создать бесплатную базу на neon.com (карта не нужна) и скопировать
   `postgresql://…?sslmode=require`.
3. Создать аккаунт на github.com и токен типа **classic** с галочкой `repo`.
4. Запустить:

   ```bash
   ./scripts/deploy_github.sh
   ```

   Скрипт создаст публичный репозиторий, зальёт код и напечатает ссылку
   и блок переменных окружения.
5. На render.com: **New → Web Service → Public Git Repository** → вставить
   ссылку на GitHub из шага 4 → Language **Docker**, Instance Type **Free** →
   добавить переменные → **Create Web Service**.
6. Настроить бесплатный пингер на `https://<сервис>.onrender.com/health`
   (cron-job.org, каждые 10 минут), чтобы Render не засыпал.

> Hugging Face Spaces для этого больше не годятся: Docker-Space требует
> платную подписку PRO, а Render не принимает ссылки на HF — только GitHub,
> GitLab и Bitbucket.

У бесплатного сервера диск временный, поэтому история чатов хранится в
PostgreSQL (`DATABASE_URL`). Локально по-прежнему можно работать на SQLite.


### Шаг 1. Перенести сессию DeepSeek

Браузер нужен только один раз — на твоём Mac. Дальше сервер работает по токену.

```bash
./.venv/bin/python scripts/export_session.py
```

Скрипт выведет готовый блок `.env` с `DEEPSEEK_TOKEN`, `DEEPSEEK_COOKIES` и
`DEEPSEEK_USER_AGENT`. Скопируй его в `.env` на сервере. Токен — секрет,
не коммить его в git.

> Второй способ: скопировать `session/session.json` на сервер
> (`scp session/session.json user@server:~/ai-tg/session/`). Но тогда для
> автообновления сессии понадобится браузер и на сервере, поэтому проще токен.

### Шаг 2. Установить и запустить

```bash
# на сервере
git clone <репозиторий> ai-tg && cd ai-tg   # или scp папку целиком
./scripts/install.sh
nano .env                                    # BOT_TOKEN, OWNER_IDS, токен DeepSeek
./scripts/start.sh                           # проверка, что запускается
```

### Шаг 3. Сделать службой (systemd)

```bash
sudo cp deploy/bot.service /etc/systemd/system/ai-tg-bot.service
sudo nano /etc/systemd/system/ai-tg-bot.service   # поправь User и WorkingDirectory
sudo systemctl daemon-reload
sudo systemctl enable --now ai-tg-bot
sudo systemctl status ai-tg-bot
journalctl -u ai-tg-bot -f                        # логи в реальном времени
```

После этого бот поднимается сам при загрузке сервера и при падении.

### Вариант через Docker

```bash
docker compose up -d --build
docker compose logs -f
```

`docker-compose.yml` уже монтирует `data/` и `session/` наружу, так что база и
сессия не потеряются при пересборке.

### Честно про DeepSeek на сервере

- Вход в аккаунт делается с твоего домашнего IP. С IP дата-центра DeepSeek
  чаще показывает проверку «не робот» и может отклонять запросы.
- Если это случится — бот не умрёт: он напишет об ошибке и ответит резервной
  моделью. А токен можно обновить, повторив `export_session` на Mac.
- Если нужна максимальная надёжность 24/7 без сюрпризов — поставь
  `DEEPSEEK_WEB_ENABLED=false` и используй бесплатный ключ OpenRouter/Groq.
  Тогда браузер и сессии вообще не участвуют.

## Картинки, видео и генерация

Бот понимает фото: можно прислать картинку или **переслать пост** из канала —
фото + подпись он прочитает вместе.

- Картинку смотрит «зрячая» модель — бесплатная модель OpenRouter. DeepSeek-веб
  фото не принимает. Никаких служебных надписей в чате нет.
- Если картинка без подписи — бот сам спросит себя, что на ней, и опишет.
- Если к фото есть подпись (например, текст новости) — ответит по сути.
- **Пересланный пост с видео:** видео пропускается, а текст (подпись) бот
  читает и отвечает по нему. Если подписи нет — вежливо скажет, что видео
  не смотрит.
- Если в альбоме есть и фото, и видео — фото разберёт, видео пропустит.
- **Ссылка на YouTube или Shorts** — бот «смотрит» видео без скачивания
  (название, описание, субтитры), пересказывает и запоминает его в текущем
  чате: можно дальше спрашивать по содержанию.
- **Своё видео по описанию**: `/video кот в космическом шлеме` или фраза
  «сгенерируй видео …» — бот пришлёт короткий ролик (2–3 секунды). Это
  бесплатно, но генерация занимает до пары минут.

Настроить, кто смотрит картинки:

```env
VISION_PROVIDER=openrouter
VISION_MODEL=nvidia/nemotron-3.5-super-vl:free
```

### Генерация картинок

Попроси «нарисуй кота в космическом шлеме» (или используй `/image …`) — бот
пришлёт картинку.

- По умолчанию бот рисует через **бесплатные нейросети на Hugging Face**:
  сначала **FLUX.1-dev**, если он занят — **SD 3.5 Large**, затем старое
  FLUX-демо. Регистрация, ключи и карта не нужны — работает сразу.
- Бесплатные GPU-пространства дают ограниченную квоту на IP. Если хочется
  стабильнее — создай бесплатный токен на huggingface.co
  (Settings → Access Tokens → Read) и добавь `HF_TOKEN=hf_...`: и картинки,
  и видео будут срабатывать чаще. Это не обязательно.
- Если добавить ключ **Cloudflare Workers AI**, бот будет рисовать через него:
  это быстрее и стабильнее. Модель —
  [FLUX.1 schnell](https://developers.cloudflare.com/workers-ai/models/flux-1-schnell/).
- Бесплатный тариф Cloudflare: **10 000 нейронов в день, без карты**. Одна
  картинка 1024×1024 стоит около 58 нейронов, то есть примерно **170 картинок
  в день**. Для личного бота этого более чем достаточно.
- Если Cloudflare не настроен или не ответил — работает бесплатный FLUX.
  Совсем последний запасной вариант —
  [Pollinations](https://pollinations.ai), без ключа. У него бесплатный лимит
  примерно 1 картинка в 45 секунд; с токеном pollen лимита нет.
- Русские запросы бот сам переводит на английский — FLUX так рисует точнее.
- Отключить бесплатные генераторы: `IMAGE_FREE_FALLBACK=false`.

Настройки:

```env
# Не обязательно: без этих строк работают бесплатные модели Hugging Face.
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_API_TOKEN=...
# IMAGE_MODEL=@cf/black-forest-labs/flux-1-schnell
# POLLINATIONS_TOKEN=...
# IMAGE_HF_SPACE=black-forest-labs/FLUX.1-dev
# IMAGE_HF_STEPS=24
# HF_TOKEN=hf_...          # бесплатный токен HF: больше квоты GPU
# VIDEO_SECONDS=2
```

## Ключ Cloudflare за 3 минуты (генерация картинок)

Ключ бесплатный, карта не нужна. Это не обязательный шаг: картинки уже
работают через бесплатный FLUX на Hugging Face. Cloudflare просто быстрее и
стабильнее, поэтому если хочется — добавь его.

1. Зарегистрируйся на https://dash.cloudflare.com/sign-up (email + пароль).
2. Открой страницу Workers AI:
   https://dash.cloudflare.com/?to=/:account/ai/workers-ai
3. Нажми **Use REST API** (или **REST API**).
4. Нажми кнопку **Create a Workers AI API Token** — Cloudflare сам подставит
   правильные права. Ничего вручную выбирать не нужно.
5. Нажми **Create API Token → Copy API Token** и сохрани токен (он показывается
   один раз).
6. На этой же странице скопируй **Account ID**.
7. Вставь обе переменные:

   - локально — в `.env`:
     ```env
     CLOUDFLARE_ACCOUNT_ID=...
     CLOUDFLARE_API_TOKEN=...
     ```
   - на Render — **Environment → Add Environment Variable**, добавить обе
     переменные → **Save Changes**.

⚠️ Если создаёшь токен вручную через **My Profile → API Tokens**, нужны
**оба** права: `Workers AI → Read` **и** `Workers AI → Edit`. С одним только
`Read` Cloudflare не даст рисовать, и бот молча уйдёт на запасной Pollinations.

После перезапуска в `/settings` будет написано **Рисую: Cloudflare (FLUX)**.

## Как это работает

```
Telegram → aiogram → чат в SQLite / PostgreSQL → провайдер → ответ потоком обратно в Telegram
```

Два типа провайдеров:

| Провайдер | Что это | Стоимость |
|---|---|---|
| `deepseek_web` | неофициальный доступ к chat.deepseek.com по токену аккаунта | бесплатно |
| `openrouter` / `groq` / `deepseek` / `custom` | обычный OpenAI-совместимый API по ключу | бесплатные тарифы |

**DeepSeek веб** работает так: один раз логинимся в браузере (Playwright),
забираем токен и cookies, дальше бот общается с сайтом напрямую по HTTP,
решая proof-of-work родным WebAssembly-модулем DeepSeek. Библиотека взята из
проекта [Tsuev/opencode-deepseek](https://github.com/Tsuev/opencode-deepseek)
(MIT) и лежит в `vendor/`.

**Резерв** включается автоматически: если DeepSeek ответил ошибкой, протух токен
или сработала защита от частых запросов — бот честно предупредит и ответит
резервной моделью, сохранив контекст беседы.

## Чаты и память

- Каждый чат — отдельная ветка со своей историей. Темы не смешиваются.
- История хранится в `data/bot.sqlite3` (SQLite), а если задан `DATABASE_URL` —
  в PostgreSQL. Ничего не теряется при рестарте.
- Для DeepSeek бот дополнительно переиспользует ветку на стороне сайта, поэтому
  не нужно каждый раз пересказывать весь диалог.
- В модель уходит последние `MEMORY_MAX_MESSAGES` сообщений и не больше
  `MEMORY_MAX_CHARS` символов — остальное остаётся в базе.
- Фото смотрит отдельная «зрячая» модель, но при продолжении ветки DeepSeek
  получает краткое напоминание о недавних репликах — поэтому помнит, что
  было на присланном фото (`HISTORY_ON_RESUME=true`).

Кнопки внизу:

- **➕ Новый чат** — начать с чистого листа;
- **🗂 Мои чаты** — список, переключение, удаление;
- **⚙️ Настройки** — провайдер, модель, DeepThink, веб-поиск.

## Настройки чата

- **Провайдер** — DeepSeek веб или бесплатная модель OpenRouter.
- **⚡ Instant / 🧠 Expert** — быстрая или более сильная модель DeepSeek.
- **DeepThink** — режим рассуждений (модель «думает» перед ответом).
- **Веб-поиск** — DeepSeek ищет в интернете (включён на аккаунте).

Настройки применяются только к текущему чату.

## Настройка резервной модели

По умолчанию выбран OpenRouter. Впиши ключ в `.env`:

```env
FALLBACK_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-...
```

Другие варианты:

```env
# Groq (бесплатный ключ: console.groq.com/keys)
FALLBACK_PROVIDER=groq
GROQ_API_KEY=...

# Официальный DeepSeek API (платный, но дешёвый)
FALLBACK_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-...

# Любая OpenAI-совместимая точка
FALLBACK_PROVIDER=custom
FALLBACK_BASE_URL=https://api.example.com/v1
FALLBACK_MODEL=some-model
FALLBACK_API_KEY=...
```

Можно вообще отключить: `FALLBACK_PROVIDER=none`.

## Полезные переменные

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `DATABASE_URL` | — | PostgreSQL вместо SQLite (нужно для хостингов с временным диском) |
| `PORT` | — | порт мини-HTTP-сервера (`/health`) для Hugging Face / Render |
| `DEEPSEEK_MIN_INTERVAL` | `3` | пауза между запросами к DeepSeek, секунды |
| `DEEPSEEK_COOLDOWN` | `60` | пауза после «слишком часто» |
| `DEEPSEEK_REFRESH_MINUTES` | `300` | как часто обновлять сессию из профиля браузера |
| `MEMORY_MAX_MESSAGES` | `40` | сколько сообщений истории отправлять модели |
| `MEMORY_MAX_CHARS` | `24000` | лимит по символам |
| `SYSTEM_PROMPT` | — | системная инструкция |
| `CLOUDFLARE_ACCOUNT_ID` | — | генерация картинок через Cloudflare FLUX |
| `CLOUDFLARE_API_TOKEN` | — | токен Workers AI (право Workers AI: Read) |
| `IMAGE_FREE_FALLBACK` | `true` | запасной генератор Pollinations |
| `POLLINATIONS_TOKEN` | — | убирает лимит Pollinations (необязательно) |
| `LOG_LEVEL` | `INFO` | `DEBUG` для подробных логов |

Полный список — в `.env.example`.

## Важно про DeepSeek

- Это **неофициальный** способ. Сайт может поменять внутренний API в любой
  момент — тогда нужно обновить `vendor/deepseek` из апстрима.
- Автоматизация веб-чата может нарушать правила DeepSeek. Чтобы не привлекать
  внимание, бот выдерживает паузу между запросами (`DEEPSEEK_MIN_INTERVAL`) и
  переиспользует ветки диалога, а не создаёт новую на каждое сообщение.
- Сессия живёт ограниченно. Если бот пишет «Сессия DeepSeek недействительна» —
  просто запусти `./scripts/ds_login.sh` ещё раз.
- Если не хочется никаких рисков — убери DeepSeek (`DEEPSEEK_WEB_ENABLED=false`)
  и работай через бесплатные ключи OpenRouter/Groq.

## Если что-то не работает

**«Нет ни одного источника ответов»** — не выполнен вход в DeepSeek и не задан
ключ резервной модели. Запусти `./scripts/ds_login.sh` или впиши ключ.

**«Сессия DeepSeek недействительна»** — токен протух: `./scripts/ds_login.sh`.

**Бот молчит** — проверь, что твой ID в `OWNER_IDS` (это число, не `@username`).

**Окно входа не открывается** — установи Google Chrome или выполни
`./.venv/bin/playwright install chromium`.

**Хочу остановить** — `Ctrl+C` в терминале, где запущен бот.
